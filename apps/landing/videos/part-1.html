Описание

Строим настоящий Fullstack-проект с AI с нуля до продакшена. В первой части создаём приложение на NestJS + Angular с Prisma и PostgreSQL, используя AI в Qoder IDE.

В этом видео начинаем разработку полноценного Fullstack-приложения и разбираем весь процесс разработки с AI:

  • AI-assisted development с Qoder IDE
  • Backend на NestJS
  • Frontend на Angular
  • ORM Prisma
  • PostgreSQL
  • Docker Compose
  • Запуск и подготовка проекта к production
  • Дальнейшее развёртывание проекта

Это первая часть серии, в которой будем постепенно развивать приложение от идеи и первоначальной настройки до полноценного production-проекта.

Стек технологий

Qoder IDE AI NestJS Angular TypeScript Prisma PostgreSQL Docker Docker Compose PM2 tuna.am
